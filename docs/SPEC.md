# 150周年記念 修学旅行復活 署名活動アプリケーション仕様書

## 1. 背景と目的
- **背景**: 現在、当校では修学旅行が実施されていない。
- **好機**: 再来年に学校創立150周年という大きな節目を迎える。
- **目的**:
  - 150周年の記念事業として、生徒たちの思い出作り・学びの機会・伝統の再興を目的とした修学旅行の復活を要望する。
  - 紙の署名用紙では紛失や改ざん、集計ミス、管理の手間が生じるため、Web/デジタルアプリを活用して確実に記録・集約・可視化・提出できるようにする。

## 2. ターゲットユーザー & 利用想定
1. **生徒**: スマホや学校配布端末（Chromebook、iPad、PC等）から手軽に署名・応援メッセージを投稿。
2. **発起人（生徒会・有志グループ）**: 署名進捗や応援メッセージの確認、学校側（校長先生、教員会議、PTA等）への提出用レポート・CSVの出力。
3. **学校関係者・教員・保護者・卒業生**: 賛同者としての署名、または生徒たちの熱意や具体的要望の確認。

## 3. アプリケーション機能要件
### (1) 趣旨説明・目標カウンター（Hero & Goal Section）
- 150周年記念と修学旅行復活にかける想い・趣旨の説明文
- 目標署名数（例: 500名など可変設定可能）に対する現在の署名数、達成率プログレスバー
- 学年別・属性別の賛同割合の可視化

### (2) 署名フォーム（Signature Form）
- **入力項目**:
  - 氏名（必須）
  - 属性（必須: 在校生 / 卒業生 / 保護者 / 教職員 / その他）
  - 学年・クラス・学籍番号（在校生の場合）または卒業年度等
  - 連絡先（学校指定メールアドレスまたは個人メールアドレス、確認用・重複防止用）
  - 署名公開設定（匿名表示可 / 実名表示 / イニシャル表示）
  - 修学旅行で行きたい場所ややりたいこと、学校へのメッセージ（任意）
  - 規約・個人情報取扱いの同意チェック

### (3) 重複署名・なりすまし防止（Duplication & Verification）
- メールアドレス/学籍番号のユニークチェック
- ローカルストレージおよびセッションによる同一端末からの連打・多重送信防止
- IP/クライアントハッシュによる簡易レートリミット

### (4) 応援メッセージボード（Voices & Messages）
- 賛同者の応援メッセージや行きたい場所のアイデアをリアルタイム表示
- 匿名希望者のプライバシー保護（名前を伏せてメッセージのみ表示など）

### (5) 管理・提出機能（Admin & Export）
- 提出用CSVエクスポート（教職員・校長提出用：氏名・学年・クラス・日時・メッセージ一覧）
- 提出用サマリーレポート（総署名数、属性別内訳、生徒の主な声・要望まとめの自動集計）
- データのバックアップ/復元機能（JSONエクスポート/インポート）

## 4. データモデル
```typescript
interface Signature {
  id: string;
  name: string;
  role: 'student' | 'alumni' | 'parent' | 'faculty' | 'other';
  grade?: string; // 1年生, 2年生, 3年生
  classRoom?: string; // 1組, 2組 など
  studentIdOrEmail: string; // 重複チェック用識別子
  displayOption: 'real_name' | 'initial' | 'anonymous';
  destinationIdea?: string; // 行きたい場所・希望
  message?: string; // 応援メッセージ・要望
  agreedToTerms: boolean;
  createdAt: string; // ISO 8601
}
```

## 5. 学校への提案・署名提出の戦略
1. **客観的データの収集**:
   - 「何％の生徒が希望しているか」「どのような学びや体験を求めているか」を数字と具体的な生徒の声で提示。
2. **150周年との結びつけ**:
   - 単なる「遊び」ではなく、「150年の歴史を紡ぎ、次世代の絆を深める記念事業」としての教育的価値（地域探究・伝統体験・平和学習等）をアピール。
3. **教員・保護者の懸念点への配慮**:
   - 費用負担、安全面、指導負担への配慮策（近場や日程短縮の柔軟な案など）を添えて提案。
